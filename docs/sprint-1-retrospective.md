# Sprint 1 Retrospective

**Owned by:** Scrum Master

This file is completed at the end of week 2. Review what your team shipped, what went well, what went poorly, and one specific process change for Sprint 2.

## What Went Well

Our team successfully set up our GitHub repository and deployed a three-tier application using Docker Compose. We got PostgreSQL, Flask, and nginx working together and configured our assigned port, 8085. We also gained experience troubleshooting issues and working together on the VM.


## What Could Be Better

One challenge our team faced was coordinating our work on the shared VM and GitHub repository. We ran into issues with Git pushes, merge conflicts, and keeping everyone's changes organized. This slowed us down because we sometimes had to troubleshoot problems before continuing with the lab.

## What We'll Do Differently Next Sprint

For Sprint 2, we will assign tasks more clearly at the beginning of the lab so everyone knows what they are responsible for. We will also communicate before making changes to shared files and coordinate our Git commits and pushes to avoid merge conflicts. This should help us work more efficiently and finish our tasks on time.
